# AI4701 计算机视觉 — 课程作业合集

SJTU 2025-2026 Spring 学期 AI4701 计算机视觉课程全部作业，围绕**工业螺丝视觉检测**这一主线，从图像矫正、目标检测、实例分割到视频多目标跟踪，逐步构建完整的工业视觉流水线。

## 作业概览

| 作业 | 主题 | 核心任务 | 关键技术 |
|------|------|----------|----------|
| **HW1** | 多视角图像俯视矫正 | 将 60 张带视角变换的螺丝图像矫正回俯视角 | SIFT/ORB 特征匹配、RANSAC、单应矩阵估计 |
| **HW2** | 螺丝目标检测与计数 | 对俯视图中的 5 类螺丝进行检测与分类计数 | YOLO 目标检测、数据标注与训练 |
| **HW3** | 螺丝实例分割 | 对单张图像中的每个螺丝进行精确像素级分割 | Grounding DINO + SAM、传统图像处理方法 |
| **Final** | 视频螺丝计数分析（团队项目） | 对传送带视频中的螺丝进行实时分类、跟踪与计数 | YOLO 实例分割、ByteTrack 多目标跟踪、光流运动估计、时序去重 |
